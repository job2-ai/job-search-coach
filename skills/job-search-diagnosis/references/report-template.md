# Report template

Translate the headings into the user's language. Keep the whole report readable in under 2 minutes.

```markdown
## Where you're stuck: Stage <n> — <name>

<Funnel line, e.g. 180 applications → 4 responses (2.2%) → 2 screens → 0 finals>
<One sentence: which conversion is the leak and how it compares to the heuristic benchmark.>
<If evidence is thin: say so and name the number that would confirm it.>

## Why (evidence)
- <Concrete finding tied to their data, resume line, JD, or interview story>
- <...2–4 bullets max>

## Keep doing
- <What already works and should not be redone>

## Next 2 weeks
1. **<Task>** — <how>. Done when: <observable check>.
2. ...
(3–5 tasks, ordered. Only for the stuck stage.)

## Re-check
Come back in <date / N applications or interviews> with: <the specific counts or artifacts>.
If <condition>, the bottleneck has moved to Stage <m>.
```

Rules
- Lead with the numbers, not encouragement.
- Each "Why" bullet must point to something the user gave you. If it's a general heuristic, label it.
- No tasks from other stages. A secondary stage gets at most one line: "Later: …".
- Don't promise outcomes, and don't recommend paid services.
